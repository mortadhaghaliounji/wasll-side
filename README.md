# Wasll Side

**Create your own “Which Side Are You On?” graphic.**

Wasll Side is a browser-only builder inspired by the visual language of Wasll Journey. It deliberately ships with **no political parties, logos, positions, examples, or other preloaded content**. Every row and every image is supplied by the user.

## Features

- French / English interface
- Fully custom title and subtitle
- Add, delete and reorder questions
- Two customizable sides per question
- Optional detail text on each side
- Upload an image independently for either side
- 3–7 choice boxes per row
- Optional choice numbers and Wasll branding
- Custom accent, background and text colors
- PNG export at 2× resolution
- No account or server-side data required

## Run locally

Open `index.html` in a browser or serve the folder with any static HTTP server.

## Content policy of the app

There is intentionally no starter dataset. A fresh canvas contains zero questions and no images. The builder is a neutral layout tool: users decide what each side represents.
